# Example: finding the original Pokémon-anime look

This is a reference-search example, not a universal character or painting recipe.

The user's successful image-search query was **`season 1 pokemon`**. They supplied actual frames and later narrowed the task to the first image below with "let's really focus here." That selected frame becomes the principal visual target for the next study.

## Principal reference

[Ash holding a Pokédex, with Pikachu in a wooded setting](https://m.media-amazon.com/images/M/MV5BYmU0MDZiNDQtZjYzNi00MGI1LTk1ZjktMjdlNDJjMDVmMmZjXkEyXkFqcGc@._V1_.jpg)

Useful observations from direct inspection:

- Tall eye whites have curved tops and comparatively flat lower edges; pupils are narrow vertical shapes.
- The face is defined by economical cheek and jaw turns and a small angular nose.
- The bent arm, wrist, hand supporting the Pokédex, and hanging fist are useful separate anatomy studies. Enlarge them to examine contour overlaps and compare their widths with the head.
- The collar and sleeves use broad shapes, with a small number of folds explaining the pose.
- Character color and shadow areas have clear boundaries. The trees combine irregular light and dark bark planes with loose, overlapping foliage masses.

Do not transplant Ash's pose, clothing, or exact face into an unrelated original character automatically. Study the construction, then apply the learned proportions and drawing decisions to the user's brief.

## Lessons from the drawing feedback

The user accepted a rough composition as a sketch while identifying weak hands and arms. Subsequent detail and color did not meet the requested draftsmanship standard. The useful correction was to restart with pencil proportions, inspect those on the actual canvas, and iterate with the user before rendering.

A generated polished image was rejected because direct drawing was central to the activity. Converting that generated image into native strokes would also miss the point of this workflow.

The professional reference is the quality target. This example does not establish that the unfinished drawing achieved it.
