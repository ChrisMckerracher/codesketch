# Supply-chain and local trust

The application ships zero third-party dependencies. Node and the browser are user-provided runtimes. `npm run verify` rejects dependency declarations, lockfiles with packages, bare third-party imports, remote source imports, and oversized source files. `.npmrc` disables install scripts and requests exact versions as defense in depth. Any future dependency proposal must include need, alternatives, exact version, provenance, license, advisory review, transitive inventory, integrity lock, and update ownership; user approval precedes adoption.

Bind HTTP to 127.0.0.1. Validate Host and Origin, require JSON for writes, emit a strict same-origin Content Security Policy, and serve an explicit static directory allowlist. Never evaluate agent commands as code. Treat project files and feedback as untrusted values. Untrusted feedback and names render as vector glyph data with invisible semantic input values, never HTML; do not require textContent for visible vector text. Persist projects atomically to a local ignored directory. Reject excessive requests and malformed imported projects before mutation.

The loopback API is available to local processes. It has no multi-user authentication and is intended for a trusted local machine. Do not bind it to public interfaces. Artwork and feedback stay local.

CLI capture uses an installed browser executable with a fresh temporary profile and the browser sandbox enabled. It owns and cleans up its browser, protocol connection, and ephemeral loopback server. Serve only explicit capture assets and one immutable snapshot; treat artwork as data. Bound capture time, output pixels, files, stdin, and network responses. Never attach to a user's browser, install a browser automatically, or execute artwork text. CLI server URLs remain loopback-only.

Native CLI builds use the installed Go toolchain with `GOTOOLCHAIN=local`, `GOPROXY=off`, `GOSUMDB=off`, and `CGO_ENABLED=0`. Reject external Go modules, replacements, vendoring, and workspace overrides; inspect the resolved package inventory as well as go.mod. Embed explicit canonical local renderer assets. The native transport disables environment proxies and redirects and checks the actual dial destination is loopback. Capture callbacks require the per-run random capability, expected Host/Origin/method/content type and bounded valid PNG. Terminate only the capture's owned browser process group and reap it before removing its profile. Output files are published atomically after validation.
